# Copy for Lumen

Write your text under each heading. Claude moves it into the code exactly as written.

### page.title
The browser tab title for the page.
Lumen


### page.headline
The page's main headline.
Turn sloppy prompts into sharp ones.

### input.label
Label for the box where the user pastes their prompt.
YOUR PROMPT


### button.optimize
The button that sends the prompt to be improved.
Transform my prompt


### result.improved.label
Heading above the improved prompt.
AFTER


### result.changes.label
Heading above the three changes.
WHAT CHANGED


### status.loading
Shown while the prompt is being improved.
Optimizing...


### error.empty_input
The user pressed the button with nothing pasted.
No prompt yet! Please type in something.


### error.too_long
The pasted prompt is over the 4,000 character limit.
Character limit reached, try shortening a bit.


### error.rate_limited
The user has made too many requests and should try again later.
Too much use, come back in a few minutes.


### error.network
The request never reached the server.
Internet down.


### error.generic
Something went wrong on our side and the user can try again.
Unknown error.


### page.subheading
The short line under the headline explaining what the tool does.
Paste how you'd normally ask AI for help. Lumen rewrites it into a prompt that actually works — and teaches you why.


### result.before.label
Heading above the user's original prompt in the before/after view.
BEFORE


### button.example
The button that fills the box with an example prompt.
Try an example


### input.placeholder
Placeholder text shown inside the empty prompt box.
e.g., 'write me a thank you email for a donor'


### page.eyebrow
The small tracked label above the headline.
PROMPT OPTIMIZER


### task.label
Label above the row of three task buttons.
Task Optimizer


### page.audience
A sentence under the subheading saying who the tool is for and what it does with their prompt.
This is for nonprofits, companies, and general employees who want to more effectively use AI by putting their initial idea in here, where it will be revised with all the things AI needs, which can be copied and put back into AI.


### button.copy
The button on the AFTER card that copies the improved prompt.
Copy


### button.copied
What that button says for a moment after copying.
Copied


### task.other
The fourth task button, for prompts that don't fit the three presets.
Anything else
